## 已確認的問題與修正

### 高：延後載入完整 CSS，導致首頁顯示錯誤內容與大幅位移

正式站手機三輪效能為 72、73、73；桌面一輪為 74，重現使用者截圖的效能分數。手機 CLS 為 0.802–1.488，桌面為 1.502。Lighthouse 的 `layout-shifts` 與 `cls-culprits-insight` 指向尚未套用樣式的 `#notice-view`。

原先 HTML 先放一份只有四首歌的指南快照；`src/bootstrap.js` 再判斷路由、清空首頁、動態載入主程式與被停用的 CSS。指南則等第一次操作才載入完整程式，讓不同路由的稽核無法代表完整功能。

修正：移除這套 bootstrap 與重複的 critical CSS。`src/ui/home.js` 同時提供 Vite 建置與前端路由使用的首頁 HTML；建置直接內嵌完整壓縮 CSS，正常啟動主程式並保留已呈現的首頁。Hash 深層連結在解析首頁前就隱藏它，路由就緒後才顯示正確畫面。沒有 Lighthouse 偵測、測試專用畫面或等待使用者操作的啟動機制。

### 高：首頁多餘的下載與同步排版

正式站首頁即使未開啟座位卡片，仍下載 375 KB 座位預覽；海報 JPEG 為 242,827 bytes。Performance trace 顯示首頁置中與啟動時視窗尺寸讀取造成同步排版，長任務隨排程時機而波動。

修正：

- 保持海報 1054 × 1492 尺寸，轉為 50,062 bytes WebP，減少約 79%。
- 座位預覽只在展開卡片後設定 `src`。
- CSS 負責初始垂直置中，展開卡片時才固定留白；標題不隨卡片展開移動。
- 收合資訊卡與關閉的公告／日誌視窗不計算其子內容版面。
- 移除啟動時不必要的視窗尺寸讀取與捲動；保留路由切換的回頂行為。

### 高：歌詞分檔未列入離線預快取

上一版把歌詞與讀音分檔，卻只把 HTML 直接引用的入口加入預快取，未能完整保留 README 所描述的離線使用方式。

修正：建置時把程式、歌詞、讀音與 CSS 背景圖片的實際雜湊網址列入 Service Worker 預快取。保留分檔載入；離線測試確認只開過首頁、完成快取後，首次進入歌曲仍能顯示歌詞。

### 中：淺色模式首頁頁尾對比不足

正式站 Lighthouse 無障礙分數為 95。頁尾文字 `#64646b` 配首頁背景 `#230805`，對比僅 3.22:1。修正首頁頁尾使用原有金色文字 token；指南頁尾仍使用其閱讀介面的顏色。

## 功能與視覺驗證

瀏覽器測試涵蓋手機 412 × 823 與桌面 1440 × 1200：

- 深淺色切換、首頁畫面、資訊卡展開／收合、展開時標題位置不動。
- 座位預覽展開前零請求、展開後正常顯示。
- 歌曲搜尋、清除、排序、36 首完整清單。
- 開啟歌曲、歌詞內容、切換讀音、切換日文顯示、返回指南與首頁。
- 劇透閘門選擇前沒有歌單項目；隨機顯示後改為演出順序仍要求確認。
- 更新日誌開啟／關閉。
- 首頁快取完成後斷網、重新載入，再首次開啟歌曲。
- 上述流程沒有未處理的頁面 JavaScript 例外。

這些測試沒有修改歌詞、應援標記或非官方歌單內容。YouTube 真實播放、螢幕閱讀器人工測試與實際裝置的 INP 不在本次自動驗證範圍。

Agentic Browsing 未單獨評分；本次保留原有具名稱、角色與狀態的控制元件，沒有為了分數加入 WebMCP 或 llms.txt。

## 重現方式

先執行 `npm run build`。以支援 gzip 的靜態伺服器提供 `dist/`；未壓縮的開發／預覽伺服器不能直接拿來比較正式站傳輸時間。稽核每個 URL、每種裝置三次，且逐次執行：

```bash
npx --yes lighthouse@13.5.0 'http://127.0.0.1:4175/' \
  --chrome-flags='--headless' \
  --only-categories=performance,accessibility,best-practices,seo \
  --output=json --output-path=/tmp/home-mobile-1.json
```

指南改用 `http://127.0.0.1:4175/#/guide`；桌面加上 `--preset=desktop`。若 Chrome 不在預設位置，設定 `CHROME_PATH`。本次完整原始報告、trace、截圖與瀏覽器測試輸出位於 `/tmp/vaundy-audit-20260923-*`，摘要另存入版本庫。

`npm run build` 與 `git diff --check` 通過。修正版尚未部署；正式站仍為舊版，發布後應以實際正式 URL 再測，包含 CDN、Cloudflare 注入腳本、舊 Service Worker 更新與真實網路延遲的影響。本機數據不能冒充發布後的正式站結果。
